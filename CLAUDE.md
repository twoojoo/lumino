# Lumino — notes for Claude

Native database IDE (DBeaver/Beekeeper alternative) in Go: Gio UI (forked from Kubeon) on top of a
driver-neutral database API with one adapter per database.

## Hard rules
- **Never connect to databases configured on this machine** (other projects run Postgres on 5432/5433).
  Only the disposable ones of `scripts/dbs/compose.yml` (`make db-up`, 127.0.0.1:55xxx) and SQLite files
  under `.dev/`. Build/run/test with the `dev` tag: `internal/safety` refuses anything else, keeps
  settings in `.dev/config` and uses an in-memory keyring.
- No paid LLM calls without asking: AI tests use mock servers (`internal/ai/*_test.go`) or local Ollama.

## Build / test
- Gio tags: `nox11,novulkan` (X11/Vulkan headers not installed; Wayland only).
- `make test` (unit), `make db-up` then `make test-int` (conformance suite of every adapter in
  `internal/db/conformance` + headless UI tests with screenshots in `.dev/shots/`), `make run`.
- Conformance: `internal/db/dbtest` runs the same checks on every database (metadata, DDL round trip,
  streaming, cancel, transactions, read-only sessions, row editing, type round trips). Fixtures per
  dialect in `internal/db/dbtest/fixtures/*.sql`. A new adapter must pass it.
- `third_party/gio` is generated by `scripts/vendor-gio.sh` (patches in `third_party/_gio-patches`).

## Layout
- `internal/db`: API (`Driver`, `Conn`, `Session`, `Result`, `Catalog`, `Dialect`), values, edits
  (`ApplyChanges`), DDL helpers, statement classification, SSH tunnels, TLS.
  `internal/db/sqlx`: line-based lexer + script splitter (dollar quotes, DELIMITER, GO, `/`, SET TERM).
  `internal/db/sqlbase`: database/sql implementation shared by adapters (hooks for cancel, kinds…).
  `internal/db/adapters/*`: postgres, cockroach, mysql (mysql/mariadb/tidb), sqlite (modernc), mssql,
  oracle (go-ora), clickhouse, firebird, cassandra (gocql, native session), trino. All pure Go.
- `internal/ui`: Gio app. `editor.go`/`editbuf.go`/`completion.go`/`findbar.go` (SQL editor),
  `grid.go` (data grid), `console.go`, `tableview.go`, `sidebar.go`, `connform.go`, `conns.go`
  (connection state + metadata cache), `aipanel.go`.
- `internal/prefs` (settings, no secrets), `internal/secrets` (OS keyring), `internal/history`,
  `internal/knownhosts` (SSH TOFU), `internal/ai` (assistant: providers, read-only DB tools, proposals).
- Mutations go through policies: read-only connections block writes, protected (production) ones
  confirm (typed for destructive statements) and start consoles in manual transaction mode.

## Packaging
- Self-update (`internal/update`) installs only releases whose SHA256SUMS.txt verifies with the built-in
  ed25519 public key; the private key is `.dev/update-signing.key` locally and the `UPDATE_SIGNING_KEY`
  repo secret in CI. Never print, commit or regenerate it. Dev builds never update.
- Packages are published to the public repo `twoojoo/lumino-releases` (creating it is the user's call).
- `make package-linux|windows|macos`, icons from `packaging/logo-source.png` (`go run ./scripts/logogen`,
  then `make icons`).
